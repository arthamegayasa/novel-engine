# Clue Ledger: {{TITLE}}

> The bookkeeping that keeps a long mystery fair. Update this file in the same commit as any chapter that plants, echoes, or pays off a clue.
> Status values: `planned` → `planted` → `echoed` → `paid` | `abandoned` (must be explained in Notes).
> Types: `plant` (first appearance), `echo` (repeat in a new light), `payoff` (reveal), `red-herring` (a fair misdirection the text later corrects), `misread` (the narrator interprets a true fact wrongly on the page), `recontext` (an earlier scene that reads differently after a reveal).

## Rules this ledger enforces

1. **Distance.** Every payoff has at least one plant at distance D or more and at least one echo between plant and payoff. Series-level payoffs (the Big Question) have at least three plants. D = 10 chapters for books of 60 chapters or more; for shorter books D = max(3, one tenth of the planned chapter count). Record the D used for this book here: **D = ___**.
2. Every plant is camouflaged: it appears in a scene whose emotional focus is elsewhere (list the camouflage method from `engine/structure/mystery-playbook.md` §3).
3. Red herrings must be *fair*: the text that misleads must be literally true or spoken by a character with a reason to lie.
4. The reader must be able to solve it in hindsight. Before any payoff, list the chapters a re-reader would point to (the `fair_play_check`).
5. No clue is abandoned silently. `abandoned` requires a note and, if the clue was prominent, an on-page acknowledgement.
6. Decoy answers get disproven on-page, never by narration simply moving on.
7. Every payoff row carries a `verbatim_hook`: the exact phrase (≤10 words) from the plant that the payoff will quote or paraphrase so the reader feels the click.

## Payoff pre-flight checklist (run before writing any payoff chapter)

- [ ] List every plant and echo for this mystery with chapter numbers.
- [ ] Re-read each plant. Does it still read as planted, not as a plot hole?
- [ ] Is there a decoy that must be disproven first? Has it been?
- [ ] Will the reveal change the meaning of at least two earlier scenes? Name them (recontext rows).
- [ ] Does the reveal create a new question? Log it as a new mystery with its own plants.
- [ ] Run the reader simulation (mystery-playbook §7) with a fresh reviewer.
