# Clue Ledger: Not Yet

> The bookkeeping that keeps a long mystery fair. Update this file in the same commit as any chapter that plants, echoes, or pays off a clue.
> Status values: `planned` → `planted` → `echoed` → `paid` | `abandoned` (must be explained in Notes).
> Types: `plant` (first appearance), `echo` (repeat in a new light), `payoff` (reveal), `red-herring` (a fair misdirection the text later corrects), `recontext` (an earlier scene that reads differently after a reveal).

**Planned numbered chapters N = 30; minimum arc/series plant-to-payoff distance D = max(3, N/10) = 3 chapters.** Future chapter numbers are schedules, not evidence of written prose.

## Rules this ledger enforces

1. Every arc/series payoff has at least one plant at distance ≥D and at least one echo before the payoff; the Big Question has at least three plants. Scene-tier observations may pay sooner when the relevant rule is already established on-page. This replaces the legacy ten-chapter wording used in the first plan review; no planned chapter numbers change.
2. Every plant is camouflaged: it appears in a scene whose emotional focus is elsewhere (list the camouflage method).
3. Red herrings must be *fair*: the text that misleads must be literally true or spoken by a character with a reason to lie.
4. The reader must be able to solve it in hindsight. Before any payoff, list the chapters a re-reader would point to.
5. No clue is abandoned silently. `abandoned` requires a note and, if the clue was prominent, an on-page acknowledgement.
6. Decoy answers get disproven on-page, never by narration simply moving on.
